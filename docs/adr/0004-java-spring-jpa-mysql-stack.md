# ADR 0004: Java·Spring Boot·JPA·MySQL 기술 스택

- 상태: Accepted
- 날짜: 2026-07-21

## 배경

서비스는 우아한테크코스 프리코스 연습을 대상으로 하며 제출, 인증, 상태 전이, 이력 조회, 비동기 작업 관리가 필요하다. 개발 코드 자체도 Java와 Spring 생태계를 연습하고 검토하기 쉬워야 한다.

## 사용자 가치

검증된 웹·트랜잭션 도구를 사용해 제출과 결과가 일관되게 보존된다. 운영자가 익숙한 생태계에서 장애를 빠르게 진단하고 기능을 지속적으로 개선할 수 있다.

## 결정

Java 21, Spring Boot, Gradle Groovy DSL, Spring Data JPA, MySQL 8, Flyway를 사용한다. Lombok은 생성자와 접근자 보일러플레이트에 제한적으로 사용한다. 서비스 클래스는 읽기 전용 트랜잭션을 기본으로 하고 쓰기 메서드만 쓰기 트랜잭션을 선언한다.

## 선택 이유

- Java 21은 장기 지원 버전이며 프리코스 학습 맥락과 일치한다.
- Spring Boot는 OAuth, REST, 트랜잭션, 검증 기능을 일관되게 제공한다.
- JPA는 일반 도메인 저장을 단순화하면서 특수 쿼리는 별도 구현으로 격리할 수 있다.
- MySQL은 운영 데이터와 초기 작업 큐를 함께 안정적으로 관리한다.
- Flyway는 운영 스키마 변경 이력을 코드와 함께 보존한다.

## 검토한 대안

- Kotlin: 표현력은 좋지만 Java 학습 목표와 팀의 선택에 맞지 않는다.
- PostgreSQL: 충분히 적합하지만 운영 DB로 MySQL을 사용하기로 결정했다.
- Redis 동시 도입: 현재 처리량에서 별도 운영 비용이 더 크다.

## 결과

JPA의 지연 로딩, N+1, 트랜잭션 경계를 주의해야 한다. MySQL 전용 잠금 쿼리는 인프라 어댑터에 격리하고 실제 MySQL로 검증한다. Lombok의 `@Data`, 엔티티 공개 setter, 무분별한 builder는 금지한다.
