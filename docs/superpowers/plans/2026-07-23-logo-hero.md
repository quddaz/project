# Logo Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the introduction home hero with the generated logo-centered visual and run it locally.

**Architecture:** The generated PNG is a Spring Boot static resource. `index.html` uses it as a responsive CSS hero background with a contrast overlay, while the problem workspace stays isolated at `problems.html`.

**Tech Stack:** Spring Boot static resources, vanilla HTML/CSS, Docker Compose, Gradle.

## Global Constraints

- Serve the image from `src/main/resources/static/images/`.
- Keep the image's central logo visible and avoid third-party copied brand assets.
- Keep the existing home text and `문제 풀러가기` command accessible above the image.
- Do not change submission, scoring, feedback, or polling behavior.
- Verify desktop and 390px mobile rendering before completion.

### Task 2: Apply the Dark Hero Composition

**Files:**
- Modify: `src/main/resources/static/index.html`

**Interfaces:**
- Consumes: `/images/woowa-practice-logo-hero.png`.
- Produces: `.intro-hero` with the image background and readable overlaid hero copy.

- [ ] **Step 1: Replace the hero surface rules**

Replace the existing `.intro-hero` style with these base declarations and add the pseudo-element rules:

```css
.intro-hero {
  position: relative;
  isolation: isolate;
  min-height: 520px;
  overflow: hidden;
  background: #030014 url('/images/woowa-practice-logo-hero.png') center bottom / cover no-repeat;
}
.intro-hero::before {
  position: absolute;
  z-index: -1;
  inset: 0;
  content: '';
  background: linear-gradient(90deg, rgba(3, 0, 20, .82), rgba(3, 0, 20, .32));
}
.intro-hero h1, .intro-hero p:not(.eyebrow) { color: #ffffff; }
.intro-hero .eyebrow { color: #ccff00; }
```

Keep the text and command in the existing semantic markup; do not add a nested card.

- [ ] **Step 2: Add the mobile composition rule**

Inside the existing `@media (max-width: 540px)` block, use:

```css
.intro-hero {
  min-height: 480px;
  background-position: 58% bottom;
}
```

Keep the current mobile text sizing and ensure the command stays above the image focal point.
